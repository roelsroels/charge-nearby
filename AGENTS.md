# Repository maintenance

- Review the README badges whenever workflows, releases, licensing, runtime requirements, packaging, or deployment change.
- Keep existing badges accurate and add a new badge only when it represents a real, useful, verifiable project capability or status. Remove stale, invalid, redundant, or vanity-only badges.
- Run `npm run check:badges` before publishing README or release changes, and confirm the latest-release badge after creating a GitHub release.
